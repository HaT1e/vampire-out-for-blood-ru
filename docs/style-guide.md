# Инструкция по переводу сцен (Out for Blood) — для агентов

Ты переводишь одну сцену ChoiceScript-игры на русский язык. Исходник — `deploy/scenes/<scene>.txt.json`
(JSON: `{"crc":..., "lines":[строки], "labels":{...}}`). Рядом лежит `<scene>.txt` — тот же текст в
исходном английском виде, с теми же номерами строк (0-based индексы совпадают).

## Формат работы

1. Смотри строки: `node _work/show.js <scene>.txt.json <start> <end>` (индексы 0-based, end не включительно).
   Можно читать и сам `.txt`.
2. Переводи ТОЛЬКО текст, который видит игрок. Не меняй структуру.
3. Результат — JSON-файл(ы) патча в `_work/patches/<scene>-a.json`, `-b.json`, … вида:
   ```json
   {"changes": {"12": "перевод строки 12", "15": "\t#перевод варианта"}}
   ```
   Ключ — индекс строки в `lines`. Включай только изменённые строки. Отступы в начале новой строки
   можно НЕ писать (скрипт сам подставит исходные), но если строка начинается с `#` — решётку сохрани.
   НЕ применяй патч сам к `.txt.json`. Просто создай файлы патчей.
4. Разбивай работу на куски по ~300–500 строк: прочитал кусок → написал патч → следующий.
   Один патч-файл на кусок. Так ничего не потеряется.
5. В конце ответа перечисли созданные файлы и число строк в каждом.

## Что НЕЛЬЗЯ менять

- Все `*команды` и их ключевые слова, имена переменных, меток, сцен, ачивок, SKU, файлов изображений.
- Числа, `%+`/`%-`, диапазоны, цены, даты в командах покупок.
- Внутренности `${...}`, `$!{...}`, `$!!{...}` — имена переменных и выражения. Переводить можно только
  литеральный текст внутри, если он там есть (редко).
- В `@{селектор вариант1|вариант2}` — селектор (имя переменной/условие) не трогать; переводить только
  варианты. Число вариантов можно увеличивать, если нужно для русского (1/2-4/5+), селектор — нет.
- BBCode-теги `[i]`, `[b]` — сами теги не трогать, текст внутри переводить.
- `*comment` — не переводить.
- Строковые значения, которые являются техническими идентификаторами:
  `trinity_skill`, `top_path`, `top_attribute`, `top_rel`, `scrying_target`, `stat_name`, `temp_name`
  (в `CheckInvalidName`), `store_type`, `gender`, `*if` c `path_of_*` и т.п. — оставлять как есть.

## Что переводить обязательно

- Повествование, описания, мысли, диалоги.
- Текст вариантов после `#` (включая текст после `*selectable_if (...)` / `*if (...)`).
- Подписи кнопок `*finish`, `*page_break`, `*page_break_advertisement`.
- Заголовки/описания `*achievement` (если встречаются в сцене).
- Альтернативный текст `*image ... <alt>`.
- Строковые значения переменных, которые видит игрок (см. таблицу ниже): имена, даты, названия
  магазина, оружия, отношения, прозвища кота и т.п.
- Текст в `*stat_chart` после имени переменной (если встречается).

## Стиль

- Второе лицо, «вы» со строчной: «вы видите», «ваш взгляд». Мысли героя — тоже «вы».
- Речь в кавычках-ёлочках: «Привет». Реплики с новой строки — с тире: — Привет.
  Внутренние кавычки — „лапки“.
- Живой литературный русский, без канцелярита; сохраняй тон (нуар, хоррор, ирония).
- Числа словами не заменяй, если это цена/характеристика.
- Не добавляй от себя абзацы/строки. Одна исходная строка → одна переведённая строка.
- Если в строке смешан текст и код — переводи только текст.

## Род и первое лицо (важно)

Игра обращается к игроку на «вы». В вариантах выбора от первого лица избегай прошедшего времени,
зависящего от рода: вместо «Я подошёл к двери» пиши «Подхожу к двери» / «Я у двери».
Если без прошедшего времени не обойтись, используй нейтральную конструкцию («мне удалось», «пришлось»).

## Проверка перед сдачей

- Число строк в каждом патче не больше ~500, JSON валиден (`node -e "JSON.parse(require('fs').readFileSync(...,'utf8'))"`).
- Ни одна `*`-команда, `${...}`, `@{}`-селектор, `[i]/[b]` не изменены.
- Все значения из таблицы — дословно как указано.
